VAULT REPAIR WORKBENCH

A controlled pipeline for inspecting, classifying, planning, approving, executing, verifying, and recording repair actions against the Grok content vault. All mutations route through the approval gate. No path bypasses the ledger.

DOMAIN: vault.grok STORAGE: R2 + D1 SESSION: existing Chrome LEDGER: append-only STATUS: approved direction | not completed repair

05 Source Proof Ladder ascending authority | weight per rung
L1
Cached Public URL
Edge cache, CDN, browser cache. Not proof. May lag the origin by minutes or hours.
Weight0.0 | rejected
L2
Verified Local File / Object
Checksummed local copy. Acceptable as input media, not as authoritative record.
Weight0.4
L3
Metadata Snapshot
Captured headers, etag, size, content-type. Proves shape; does not prove bytes.
Weight0.6
L4
D1 / Index Row
Canonical pointer + state flag. Authoritative for routing; trails R2 in consistency.
Weight0.8
L5
R2 Object
Source-of-truth bytes + etag. Highest storage authority. Conditional writes use this etag.
Weight1.0 | canonical
L6
Live Grok | Existing Chrome Session
Runtime source-of-truth for identity and current processed cursor. Required for any state-changing op.
WeightGATE | required
06 Research Lessons hard-won | encoded into the pipeline
L.01
LESSON | STORAGE
Direct R2 is consistency source
Index and cache lag the object store. Resolve conflicts by reading R2 directly with etags.
L.02
LESSON | WRITES
Conditional writes only
Every mutation carries a precondition. Lost races abort instead of overwriting silently.
L.03
LESSON | AUDIT
Append-only repair ledger
Receipts are hash-chained and immutable. Replay yields identical verifier output.
L.04
LESSON | EXECUTION
Idempotent actions
Every action specifies its expected post-state. Re-running a recorded step is a no-op.
L.05
LESSON | ORDERING
Read-only check before repair
A successful T0 pass is a prerequisite to scheduling any T1+ action. No scan, no plan.
L.06
LESSON | PROOF
Cached public URLs are not proof
A 200 from the edge proves cache state, not origin state. Never use as repair authority.
