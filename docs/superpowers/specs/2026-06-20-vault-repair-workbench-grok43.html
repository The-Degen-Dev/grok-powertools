Research Lessons

Direct R2 and S3/Worker reads are proof. Cached public URLs are not.
R2 restore uses conditional writes. Existing canonical objects are never silently replaced.
Every action gets an idempotency key so retries do not duplicate repair.
The app owns a ledger because R2 audit logs do not record object data writes.
Read-only check/report comes before any repair action.
Live Grok repair runs through the existing Chrome session only.
