Design Decisions

  • Adapt the subagent-driven-development skill for QA execution. Subagents may run safe local or artifact work, while the main coordinator retains exclusive ownership of the live Grok Chrome tab.
  • Use the plan and spec as source of truth instead of inferring behavior from previous run memory.
  • Use the plan's AppleScript plus Peekaboo path for existing Chrome because agent-browser and plwr are not installed in this shell.

Deviations

  • The generic subagent skill references code changes, commits, and code-quality review. This run overrides those parts because the approved goal is QA-only with no product source edits, commits, or pushes.
  • The plan's npm --prefix web exec -- next dev --port 3011 command started Next from the repo root and failed to find web/app. The server was started from the web/ working directory with the same Next dev command instead.
  • The first web script left the clipped Prompt Library modal open after failure, which caused later Settings and Sign In click attempts to be intercepted. A supplemental pass used fresh pages to separate product failures from test cascade effects.
  • No extension popup tab was open at baseline. A popup tab was opened at chrome-extension://bcjoehhhmhpjmlmjhojcokmfeafcmimd/popup.html inside the existing Chrome window after confirming none existed.
  • Live Chrome screenshots that may have shown prior private prompt text were replaced with redacted placeholder images. This preserves privacy at the cost of losing visual detail for those specific milestones.
  • Stopped all live Chrome actions after the image poll loop detected a wrong active tab. The plan expected the active tab to remain the proven Grok tab, but the runtime state changed during polling.

Tradeoffs

  • Keep implementation notes in the repo for durable progress tracking, while keeping evidence artifacts under /private/tmp to avoid committing screenshots, account state, or generated QA data.
  • Delegated local gates to a subagent because they are isolated shell checks with no live Chrome state. The main session independently re-read the generated JSON before proceeding.
  • Stopped before image submission because the goal explicitly says to pause if evidence may contain private prompts. Continuing safely requires a sanitized resume path that avoids recording live composer text and saved prompt titles.
  • After resume, the image poll loop redacted screenshots immediately and omitted media URLs, but it did not re-prove the exact tab before each individual poll. The wrong-tab detection in poll data is therefore treated as contamination and the remaining live steps are skipped.
