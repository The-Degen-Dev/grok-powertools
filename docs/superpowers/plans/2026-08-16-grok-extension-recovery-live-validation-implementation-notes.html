Deviations

Task 3 intentionally used all five review rounds and carried one completion-handoff race into Task 4. Task 4 also used all five rounds because uncancelable Chrome storage writes required a broader immutable-record and terminal-checkpoint protocol than the original snapshot design. Its remaining narrow writer-authority ambiguity became Task 5's first gate and is now closed. Task 5 deferred one minor timing-test precision check to final review; the runtime requires both stable rounds and elapsed time. Live Tasks 10-14 are controller-operated because their persistent existing-Chrome state cannot be transferred safely to a worker. During Task 10 setup, one broad Chrome accessibility capture and one frontmost Peekaboo capture that landed on Firefox returned more metadata than intended; neither was used for tab discovery or control, and that route is retired. A later Chrome menu inspection also exposed visible tab/history labels without selecting or manipulating them; it will not be repeated. The built-in Chrome bridge remained unavailable despite passing local diagnostics, so the exact visible Saved page was inspected through a single DevTools context; callback-style storage access worked while Promise-style access hung. A Peekaboo clipboard restore slot also failed after copying the non-secret Worker URL; the clipboard was later cleared after secret entry. Two cancellation-controller timing misses completed acceptance-only video uploads before Stop; they are recorded as failed harness attempts, not cancellation proof. No acceptance object is being deleted to hide those misses.
