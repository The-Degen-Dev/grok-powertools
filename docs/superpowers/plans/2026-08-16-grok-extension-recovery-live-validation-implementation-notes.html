Cancellation Authority Hardening: 2026-08-18

Design decisions. Commit 07a0c3e makes Stop optionally lease-scoped while preserving the existing unscoped popup Stop contract. A scoped request is accepted only when token, epoch, kind, and runtime sender tab match the active lease. Stop now returns transferDrained, and durability reports deterministic per-lease task counts such as media_upload, media_transfer, and processed_ids.

Harness interpretation. The ignored acceptance controller arms before Start and resolves exact authority from a newly written immutable local run record or the authoritative started response. It does not depend on chrome.storage.session, which is unavailable in the injected content-script world. It polls durability at 10 ms and requires abort acknowledgement, successful drain, stale Stop rejection, stale transfer rejection, zero run-owned queue or pending work, and an unchanged processed-ID count, digest, and exact-target membership.

Tradeoff. No test-only delay or acceptance-only runtime hook was added. Pre-arming through the existing owner-tab storage mirror avoids changing production start timing while closing the response-before-watcher race.
