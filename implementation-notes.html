Running Notes

Date Type Note
2026-05-19 Design decision The implementation will keep Watch Mode inside the existing FullscreenViewer and put queue/movie helpers in web/src/lib/watch-mode.ts, matching the approved spec.
2026-05-19 Tradeoff Added a separate playwright.web.config.js instead of changing the existing extension E2E config, so extension tests keep their current browser setup.
2026-05-19 Design decision The web Playwright fixture seeds only the minimal v1 IndexedDB schema from /favicon.ico, then lets the React app run its normal database upgrades on load.
2026-05-19 Design decision The web E2E config intentionally does not reuse existing dev servers, so validation cannot silently run against a stale server from another worktree.
2026-05-19 Deviation The plan originally used port 3001, but web E2E uses 3101 to avoid validating against manual or other-worktree dev servers on the app's default port.
2026-05-19 Design decision Watch Mode clamps previous/next at queue boundaries and disables per-video looping so natural playback can advance on ended. The non-watch fullscreen viewer keeps its existing wraparound and loop behavior.
