2026-05-19 Design decision The implementation will keep Watch Mode inside the existing FullscreenViewer and put queue/movie helpers in web/src/lib/watch-mode.ts, matching the approved spec.
2026-05-19 Tradeoff Task 2 red-test work in the working tree uses a separate playwright.web.config.js instead of changing the existing extension E2E config, so extension tests keep their current browser setup.
2026-05-19 Design decision The pending Task 2 web Playwright fixture seeds only the minimal v1 IndexedDB schema from /favicon.ico, then lets the React app run its normal database upgrades on load.
2026-05-19 Design decision The pending Task 2 web E2E config intentionally does not reuse existing dev servers, so validation cannot silently run against a stale server from another worktree once Task 4 commits it.
2026-05-19 Deviation The plan originally used port 3001, but the pending Task 2 web E2E config uses 3101 to avoid validating against manual or other-worktree dev servers on the app's default port.
2026-05-19 Design decision Watch Mode clamps previous/next at queue boundaries and disables per-video looping so natural playback can advance on ended. The non-watch fullscreen viewer keeps its existing wraparound and loop behavior.
2026-05-19 Deviation Although the plan replaced the old slideshow timer, the implementation preserves it for non-watch per-card fullscreen so existing S shortcut, slideshow interval, and loop controls stay intact.
2026-05-19 Design decision Watch Mode boundary navigation is both visually disabled at queue ends and guarded with a no-op clamp. Save-as-movie failures are caught and surfaced in the viewer, and bottom controls wrap on narrow screens.
2026-05-19 Design decision Per-card fullscreen expansion remains non-watch mode. Watch All and Watch Selected are the only entry points that enable continuous queue playback and Save as Movie.
2026-05-19 Test interpretation The web E2E watch-mode assertion uses exact text for the Watch Mode badge because the seeded collection is named Watch Mode Test, which also appears in the sidebar and viewer source label. Viewer controls and prompt assertions are scoped to the fullscreen overlay so card-grid text and the Next.js dev-tools button cannot satisfy watch-mode checks.
2026-05-19 Test wiring The web watch-mode regression now has a root test:e2e:web script, and the default test script runs unit tests, extension E2E, and web E2E while keeping test:e2e extension-only.
2026-05-19 Design decision The collection header and bulk action bar wrap at narrow widths after adding watch actions. Watch entry points are disabled from computed playable queues, with the existing empty-queue toast kept as a race-condition fallback. Opening a watch queue exits multi-select so the bulk action bar cannot sit above fullscreen viewer controls.
2026-05-19 Verification fix Final root verification exposed a stale extension E2E Chrome mock: content.js now calls chrome.runtime.getURL while injecting its bridge. The mock was updated so npm test validates both the existing extension overlay and the new web watch-mode regression suite in one command.
2026-05-19 Test wiring The web Playwright server injects a deterministic AUTH_SECRET for E2E runs. This keeps Auth.js session polling from producing missing-secret errors while still leaving production and local app configuration untouched.
2026-05-19 Design decision Browser smoke testing found the expanded collection sidebar could intercept the mobile Watch Selected action bar. The sidebar now uses the compact rail below the sm breakpoint, while desktop and manually collapsed behavior keep the existing sidebar controls.
2026-05-19 Design decision The same mobile smoke pass found the global header nav overflowed at phone width. Header navigation now becomes icon-first on small screens, with titles preserved for tooltips and full labels retained on wider viewports.
